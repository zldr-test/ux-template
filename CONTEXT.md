# ux-template

This context covers the Storybook template used to explore GenUI screens and their onboarding flows in the Sage design system.

## Language

**Figma MCP**:
The optional Figma integration a user can connect to enable Figma-backed assistance in the template.
_Avoid_: Figma login, Figma setup

**Connect Figma**:
The user's explicit action to link their personal Figma account to the template.
_Avoid_: Login with Figma, sign in with Figma

**Figma connection step**:
A skippable onboarding step that explains the Figma integration and offers the user a chance to connect it.
_Avoid_: Mandatory setup, forced login
